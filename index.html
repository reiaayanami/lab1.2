Про Git

Розумієш, що таке контроль версій?

Що таке система контролю версій?

Система контролю версій (VCS) — це інструмент, який відслідковує всі зміни в коді. Git був створений Лінусом Торвальдсом у 2005 році для управління ядром Linux.

Чому Git настільки потужний?

  • Розподілена архітектура - кожен має повну копію
  • Блискавична швидкість навіть на великих проектах
  • Невеликий набір команд, але дуже гнучкі
  • Стабільність завдяки SHA-1 хешуванню
  • Інтеграція з GitHub, GitLab, Bitbucket
  • Індустріальний стандарт для розробки

Переваги Git

Чому розробники вибирають Git

📦

Локальна робота

Працюй без інтернету. Усі операції виконуються локально з повною історією змін.

⚡

Надзвичайна швидкість

Git операції надзвичайно швидкі навіть на велику проектах завдяки локальному сховищу.

👥

Командна робота

Легко колаборуй з тисячами розробників без конфліктів і затримок.

🌿

Розгалуження (Branching)

Створюй ізольовані гілки для експериментів без впливу на основний код.

⏮️

Повна історія

Повна історія проекту дозволяє відстежити еволюцію та повернутися до будь-якої версії.

🔍

Прозорість

Бачь точно, хто змінив що, коли і чому завдяки детальним commit повідомленням.

10 Базових Команд

Командний арсенал розробника

1
git init
$ git init
Ініціалізує новий репозиторій Git у поточній папці. Створює приховану папку .git з усією необхідною структурою.
2
git clone
$ git clone <url>
Копіює (клонує) існуючий репозиторій з сервера на ваш комп'ютер. Отримуєте повну історію проекту.
3
git add
$ git add . або git add <file>
Додає файли до staging area (індекс) для підготовки до commit. "." додає всі змінені файли одразу.
4
git commit
$ git commit -m "Your message"
Зберігає snapshot поточного стану проекту з описом змін. Створює точку в історії, до якої можна повернутися.
5
git push
$ git push origin <branch>
Завантажує ваші локальні commits на віддалений сервер (GitHub, GitLab тощо). Діли свою роботу з командою.
6
git pull
$ git pull origin <branch>
Завантажує останні зміни з віддаленого репозиторію та об'єднує їх з вашою локальною гілкою. Тримай свій код в синхронізації.
7
git branch
$ git branch або git branch <name>
Показує список всіх локальних гілок або створює нову гілку. Ідеально для розробки нових функцій ізольовано.
8
git checkout
$ git checkout <branch>
Переключається на іншу гілку або версію коду. Комбіні git checkout -b для створення та переходу на нову гілку.
9
git merge
$ git merge <branch>
Об'єднує зміни з іншої гілки в поточну. Використовується для завершення розробки функції та інтеграції коду.
10
git status
$ git status
Показує поточний стан робочої директорії: модифіковані файли, файли в staging area та нові файли. Твій best friend!
